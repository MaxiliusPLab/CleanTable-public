# CleanTable 0.12.16 Public Beta Notes

Last updated: 2026-06-04

Traditional Chinese version: [CleanTable 0.12.16 公開測試版說明](release-0.12.16.zh-TW.md)

CleanTable 0.12.16 is a public beta version published on the Chrome Web Store.

CleanTable helps you turn visible web page data into a clean table. You select the part of the page you want, check the preview, edit it if needed, then copy or download the result for Excel, Google Sheets, LibreOffice Calc, or another spreadsheet tool.

## Beta Notice

CleanTable is still in beta. It works well with many common tables, lists, and cards, but some web pages may still need manual cleanup.

If something does not work as expected, please send feedback through the support page.

Please do not send private, sensitive, or account-only page content.

## What You Can Do

- Select visible data on a web page.
- Preview the table before copying.
- Edit column names and cell text.
- Add or remove rows and columns.
- Copy the table to Excel or Google Sheets.
- Download CSV.
- Copy Markdown.
- Keep several temporary sheets in the same tab while working.
- Copy selected sheets together.
- Optionally include URL columns when a table contains links.

## Works Best With

- Web tables.
- Table-like layouts.
- News lists.
- Product lists.
- Contact or address lists.
- Tables that include links.

CleanTable uses general layout detection. It does not depend on special rules for one specific website.

## Privacy

CleanTable runs in your browser. It does not upload page content, require an account, use cloud processing, or connect directly to Google Sheets.

CleanTable only reads visible text and links after you start the extension and select a page area.

See the [Privacy Policy](privacy-policy.md) for details.

## Current Limits

CleanTable does not currently extract text from:

- Images or screenshots.
- PDF files.
- Page areas where the text cannot be selected or read as normal page text.

CleanTable also does not:

- Crawl websites automatically.
- Turn pages automatically.
- Process many URLs in bulk.
- Log in to websites.
- Fill out forms.
- Store your tables in the cloud.

Some complex pages may create extra columns, missing fields, or mixed content. You can use the preview editor to clean up the result before copying.

CleanTable Privacy Policy

Last updated: 2026-06-02

繁體中文

CleanTable 是一個 Chrome 擴充功能，用來把使用者主動框選的網頁可見資料整理成乾淨表格，方便貼到 Excel、Google Sheets 或其他試算表工具。

資料處理方式

CleanTable 在瀏覽器本機執行。使用者必須主動啟動 CleanTable 並框選目前網頁上的資料區域，CleanTable 才會讀取該範圍內可見的文字與連結。

框選內容只用來產生可預覽、可編輯的表格，以及使用者主動觸發的複製、CSV 下載或 Markdown 複製功能。

資料收集與分享

CleanTable 不會收集、販售、傳輸或分享使用者資料。CleanTable 不會上傳網頁內容，不會使用雲端同步，不需要帳號，也不會把資料送到遠端服務處理。

暫存資料

CleanTable 會使用 Chrome 提供的暫時性本機儲存能力，保存同一分頁中的暫時表格工作區，讓使用者在同一分頁重新整理後可以重新打開暫存結果。

這些暫存工作表不是長期儲存，也不是雲端儲存。使用者可以按「清空整理區」移除暫存工作區。CleanTable 不承諾在關閉分頁、重新啟動瀏覽器或切換網站後仍可恢復資料。

網路與自動化

CleanTable 不會自動爬取網頁、不會自動翻頁、不會提交表單、不會登入網站，也不會連接 Google Sheets 或其他試算表帳號。

權限用途

CleanTable 只要求支援使用者主動框選、預覽、編輯、複製與下載表格所需的 Chrome 擴充功能權限。CleanTable 不要求所有網站的永久存取權，也不宣告廣泛的網站主機權限。

限制

CleanTable 目前只處理網頁上可見且可讀取的文字與連結。它不會從圖片、截圖、PDF 或無法直接選取文字的畫面擷取文字。

English

CleanTable is a Chrome extension that turns user-selected visible web page data into clean tables for Excel, Google Sheets, and other spreadsheet tools.

How CleanTable Processes Data

CleanTable runs locally in the browser. It reads visible text and links from the current web page only after the user manually starts CleanTable and selects a page region.

The selected content is used only to create an editable table preview and user-triggered copy, CSV download, or Markdown copy exports.

Data Collection and Sharing

CleanTable does not collect, sell, transmit, or share user data. CleanTable does not upload page content, use cloud sync, require an account, or send selected content to a remote processing service.

Temporary Workspace Storage

CleanTable uses Chrome's temporary local extension storage to keep the current tab's table workspace available after a same-tab page reload.

These session sheets are not long-term storage and are not cloud storage. Users can remove the temporary workspace with the Clear Workspace action. CleanTable does not promise recovery after closing the tab, restarting the browser, or navigating to a different site.

Network Use and Automation

CleanTable does not automatically crawl websites, follow pagination, submit forms, log in to websites, or connect to Google Sheets or other spreadsheet accounts.

Permissions

CleanTable requests only the Chrome extension permissions needed for user-triggered selection, preview, editing, copying, and downloading table output. CleanTable does not request permanent access to all websites and does not declare broad host permissions.

Limitations

CleanTable currently works with visible readable web page text and links. It does not extract text from images, screenshots, PDFs, or pages where text cannot be directly selected or read from the page.

# CleanTable 0.12.28 Update Notes

Last updated: 2026-06-07

Traditional Chinese version: [CleanTable 0.12.28 更新說明](release-0.12.28.zh-TW.md)

CleanTable 0.12.28 is a small public beta update.

## What Changed

- Added a small feedback link in the preview/result area.
- The link opens the public [Support and Feedback](support.md) page in a new tab.
- Added English and Traditional Chinese text for the feedback link.
- No new extension permissions were added.

## Privacy

CleanTable does not upload page content automatically. Users choose what to include when sending feedback.

## What Did Not Change

Extraction, table parsing, editing, copy, CSV, Markdown, batch copy, and sheet management behavior did not change.
